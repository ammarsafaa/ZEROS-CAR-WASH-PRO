# خطة لوحة التراخيص المركزية

## النتيجة
إنشاء مشروع ويب مستقل خاص بالبائع لإدارة تراخيص **ZEROS CAR WASH PRO**، وربط نسخة Windows به دون نقل بيانات المغسلة أو كشف بيانات العملاء التشغيلية.

## ما ستتضمنه اللوحة
- تسجيل دخول آمن للمدير، مع ملف شخصي ودور منفصل يسمح بإضافة موظفين لاحقاً.
- ملخص بعدد العملاء، الأجهزة، التراخيص الفعالة والموقوفة، وآخر اتصالات البرامج.
- إدارة العملاء: الاسم، المغسلة، الهاتف، الملاحظات، وحالة الحساب.
- إدارة الأجهزة: رقم الجهاز، اسم الجهاز، إصدار البرنامج، أول وآخر اتصال.
- تراخيص دائمة فقط: إنشاء، تفعيل، نقل إلى جهاز آخر، إيقاف، وإعادة تفعيل.
- سجل تدقيق لكل إنشاء أو تغيير أو إيقاف، مع اسم المنفّذ والوقت.
- بحث وفلاتر ونسخ رمز التفعيل، من دون إظهار أسرار داخل المتصفح.

## سلوك برنامج العميل
- يفعّل الجهاز برمز تصدره اللوحة، ثم يحتفظ بإثبات ترخيص موقّع محلياً.
- يبقى البرنامج عاملاً بالكامل بلا إنترنت، كما طلبت.
- عند توفر الإنترنت يفحص الحالة تلقائياً ويرسل فقط رقم الجهاز وإصدار البرنامج؛ لا يرسل فواتير أو عملاء أو بيانات المغسلة.
- إيقاف الترخيص عن بُعد يسري عند أول اتصال لاحق. لا يمكن تقنياً إيقاف جهاز لم يتصل بالإنترنت مع إبقائه يعمل دون إنترنت.
- عند الإيقاف يمنع الدخول التشغيلي ويعرض رسالة واضحة، مع إبقاء البيانات محفوظة وعدم حذفها.

## الأمان
- قاعدة بيانات مركزية وصلاحيات محمية عبر Lovable Cloud.
- الأدوار في جدول مستقل، والتحقق من المدير يتم على الخادم لا داخل المتصفح.
- رموز تفعيل عشوائية تُخزّن بصيغة مشفّرة/مجزأة، واتصالات البرنامج تستخدم واجهة محمية ومدخلات متحققاً منها.
- كل جهاز يحصل على إثبات موقّع لا يمكن توليده من نسخة البرنامج نفسها.

## مراحل التنفيذ
1. إنشاء المشروع المستقل وتفعيل قاعدة البيانات وتسجيل الدخول.
2. بناء جداول العملاء والأجهزة والتراخيص وسجل التدقيق والسياسات الآمنة.
3. بناء لوحة الإدارة وصفحات العملاء والأجهزة والتراخيص.
4. إنشاء واجهة التفعيل والفحص الآمنة.
5. تحديث برنامج Windows الحالي ليستعمل التفعيل المركزي مع دعم العمل دون إنترنت.
6. اختبار التفعيل، النقل، الإيقاف، إعادة التفعيل، وانقطاع الإنترنت من البداية للنهاية.

## قرار معتمد
الترخيص دائم، واللوحة مشروع مستقل، وبرنامج العميل يعمل دون إنترنت؛ لذلك الإيقاف البعيد مؤجل حتى أول اتصال لاحق.
